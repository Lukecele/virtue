# Contributing to Virtue

We welcome contributions to the Virtue conversational counseling interface and tokenomics engine.

## How to Contribute
1. Fork the repository.
2. Create a feature branch: `git checkout -b feat/your-feature-name`.
3. Verify that all unit tests pass (`npm test`) and linter checks pass (`npm run lint`).
4. Ensure production builds succeed cleanly (`npm run build`).
5. Open a Pull Request against `main` describing the changes.

## Security Disclosures
For any security-sensitive vulnerabilities, please review [SECURITY.md](./SECURITY.md).
