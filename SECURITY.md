# Security Policy

| Version | Supported |
|---------|-----------|

## Reporting a Vulnerability

If you discover a security vulnerability or responsible disclosure issue, please do NOT open a public GitHub issue.

Please report vulnerabilities directly to:
- **Email:** `security@arbitrage-inc.exchange`
- **Telegram:** [Arbitrage Inception Telegram](https://t.me/ArbitrageInception)

### What to Include
- Detailed description of the potential vulnerability
- Reproduction steps or payload example
- Expected vs actual behavior and impact assessment
- Suggested mitigation (if any)

We acknowledge vulnerability submissions within 48 hours.

## Scope
- Application interface code in this repository
- Deterministic NLP parser engine (`app/api/absolution/route.ts`)
- Client-side tokenomics and reflection calculators
